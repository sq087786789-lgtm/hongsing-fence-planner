中文使用說明與 AI 重建

上慶圍籬配置工作室可拖拉配置圍籬與雙開大門，預覽立體與平面圖，計算管夾配件並輸出規格與參照線稿。

如何操作

  1. 拖拉左側樣式新增圍籬，或套用到既有段落；圍籬可選 0 到 4 根橫桿。
  2. 在右側選取段落，設定長度、高度、管徑、網材、底板或埋管，以及上橫桿的環帽或橫通管夾。
  3. 「移動畫面」拖動整張圖；「編輯立柱」調整端點；「旋轉視角」改變觀看方向。各段轉彎角度可選獨立調整。
  4. 檢查配件計算與手動增減，再依需要關閉個別輸出項目。「參照線稿」可預覽尺寸與配件標示。
  5. 用「匯出設計」保存可重新編輯的 JSON；換裝置後用「載入設計」還原。

設計資料與修改同步

設計自動儲存在目前裝置的瀏覽器，GitHub 更新程式不會同步客戶設計。公開入口只提供工具程式與規格，不包含你的本機訂單。交接客戶設計時，請另外將 JSON 檔交給指定的人。

AI 讀到原始程式不代表取得 GitHub 寫入權限。後續修改需測試、更新發布檔，再由已授權的帳號提交與部署。
